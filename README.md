# Model Lineup

Run one image brief and the same reference images through three AI image models side by side, add notes, and export the comparison to PowerPoint.

**Open it:** https://clarissaractliffe-ops.github.io/model-lineup/

- API keys you enter are stored only in your own browser and sent only to OpenAI or Google.
- Comparisons are saved in your browser (IndexedDB), not in this repository.
- Columns set to "Add by hand" accept images from any other app.
